# System Designs for AI Engineers

A visual learning repo that turns system design ideas from Martin Kleppmann's *Designing Data-Intensive Applications* (DDIA) into original explanations, diagrams, and practical examples—with an AI engineering lens.

## Start here

Follow this learning path:

1. Build the vocabulary and design process in [00-FOUNDATIONS](00-FOUNDATIONS/system-design-fundamentals.md).
2. Work through each foundation topic in the order below.
3. Study DDIA topic by topic, following the contents of the copy used for this project.
4. Connect the concepts to AI engineering systems and case studies where relevant.

### Foundations

1. [System design fundamentals](00-FOUNDATIONS/system-design-fundamentals.md)
2. [Client–server architecture](00-FOUNDATIONS/client-server-architecture.md)
3. [Monolith vs. microservices](00-FOUNDATIONS/monolith-vs-microservices.md)
4. [Latency, throughput, and availability](00-FOUNDATIONS/latency-throughput-availability.md)
5. [Horizontal vs. vertical scaling](00-FOUNDATIONS/horizontal-vs-vertical-scaling.md)
6. [CAP theorem](00-FOUNDATIONS/CAP-theorem.md)

**Current progress:** The six foundation notes are in place. Next, we’ll begin DDIA Chapter 1: reliable, scalable, and maintainable applications. See [ROADMAP.md](ROADMAP.md) and [LEARNING-TRACKER.md](LEARNING-TRACKER.md) for progress.

## How the notes are made

Each topic is explained in concise, original wording. Notes use original diagrams and examples, then connect the idea to AI engineering when that connection is useful. References point back to DDIA and supporting learning resources. This repo is a learning companion, not a replacement for the book; it does not reproduce book passages or figures.
