# System Designs for AI Engineers

A visual, practical learning repository for understanding system design through Martin Kleppmann's *Designing Data-Intensive Applications* (DDIA), then connecting those ideas to AI engineering systems.

## What this repository is

I am working through the 2017 first edition topic by topic. For each topic, I will create a concise explanation in my own words, an original visualization, and a practical engineering connection. Where it fits, I will add an AI systems perspective and explain the design tradeoffs.

This repository is a learning companion, not a replacement for the book. It does not reproduce the book's text or figures. Please use the book as the primary source and follow its chapter order and terminology.

## Project roadmap

See [ROADMAP.md](ROADMAP.md) for the chapter-by-chapter plan and progress.

## Planned learning entry format

Each topic entry will aim to include:

- The core idea, explained briefly
- An original diagram or visual
- A practical system design example
- An AI engineering connection, when relevant
- Key tradeoffs and questions to explore
- A reference to the corresponding book chapter or section

AI engineering notes and case studies will grow alongside the book notes rather than replacing the book as the foundation. Entries are organized by book topic, with the author credited here and in relevant references.
